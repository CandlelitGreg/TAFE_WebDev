Adding New Tasks:

  • To add a new task, insert Task Name, Due Date, and Priority before clicking Add Task
  • You can also assign a consultant before selecting Add Task, however this is not required
  • To add a consultant you can search either their name, role, or both
  • Any available staff matching your search will appear in the drop down options

Displaying Tasks:

  • Tasks will be displayed in the order they are created
  • Displayed Tasks can be marked as completed by selecting the complete button on their respective row
  • Completed Tasks are also able to be deleted by selecting the Delete button which will replace the Complete button upon selection

Searching Tasks:

  • To search a task, input your search term in the search box and select Search Tasks
  • If there is a task name which contains your searched term, it will be displayed in the table
  • Should your search term not return any results the table will notify you as such
  • Once you have conducted your search, the searchbox will clear, and the Search Tasks button will be replaced with a Show All Tasks button
  • Selecting this button will revert the table to display all stored tasks
